I. Tech Stack Hiện Đại (Proposed Stack)

Mobile Client (Flutter)

Frontend
  • State Management: flutter_bloc kết hợp với freezed để sinh mã hóa an toàn, không lỗi trạng thái.
  • Dependency Injection: get_it & injectable để tối ưu hóa việc quản lý vòng đời tài nguyên.
  • Networking: dio cho REST (Video/Auth) & gRPC cho các dữ liệu thời gian thực có hiệu năng siêu cao.
  • AR Engine: Tích hợp native qua MethodChannel (ARCore cho Android / ARKit cho iOS).
  • Video Player: video_player phối hợp với preload_page_view tối ưu tải trước mượt mà.
  • Local Cache: Sử dụng NoSQL isar siêu tốc để lưu trữ đệm dữ liệu ngoại tuyến (offline cache).

Backend Engine (Go)

Services
  • Web Framework: Gin/Fiber cho RESTful endpoints hiệu suất cao & gRPC-Go phục vụ giao tiếp microservices.
  • Database & GIS: PostgreSQL kèm phần mở rộng PostGIS chuyên dụng tính toán dữ liệu bản đồ.
  • Caching & Pub/Sub: Redis cho dữ liệu nóng và OTP; hàng đợi tin nhắn bất đồng bộ Kafka hoặc RabbitMQ.
  • Object Storage & CDN: Cloudflare R2 hoặc AWS S3 để lưu trữ thô; tích hợp Cloudflare Stream / Mux để chuyển mã luồng.

II. Phân Rã Chi Tiết Tính Năng (Feature Spec)

1

Auth & User Management (Quản lý định danh)

Hỗ trợ đăng nhập đa phương thức qua Firebase Auth (Google, SMS, Apple). Trả Token ID về Go Backend để kiểm tra tính hợp lệ và phát hành JWT mã hóa riêng cho người dùng. Thiết kế thêm hệ thống "Trò chơi hóa" tích lũy điểm EXP khi người dùng đóng góp nội dung, thăng cấp từ "Nhà Thám Hiểm" đến "Thợ Săn Quán Ẩn".

2

Bản Đồ & Tìm Kiếm Không Gian (Geospatial)

Sử dụng bản đồ vector tùy chỉnh giao diện (Mapbox/Google Maps). Tính toán nhanh chóng bằng PostGIS để hiển thị toàn bộ địa điểm tiềm năng trong bán kính khảo sát được chọn lọc theo phong cách cụ thể (Chunky, Retro, Industrial...) hoặc mức độ thử thách để khám phá.

3

AR Wayfinder (Chỉ đường thực tế tăng cường)

Khi người dùng tiếp cận bán kính 100 mét gần "Gem", thiết bị cho phép kích hoạt chế độ Camera AR. Hệ thống kết hợp dữ liệu GPS của thiết bị, cảm biến la bàn số để chiếu bản dựng mũi tên 3D và thẻ thông tin nổi trên màn hình trực quan, hướng dẫn đi vào ngõ hẻm chính xác.

4

TikTok-style Video Review (Feed Luồng video ngắn)

Thao tác vuốt mượt mà để chuyển đổi video đánh giá góc sống ảo. Tích hợp chuyển mã HLS phân luồng chất lượng tương thích tốc độ kết nối internet. Tự động đệm trước (preloading) video kề cận giúp người xem không bị gián đoạn và tối ưu hóa tài nguyên RAM bộ nhớ đệm thiết bị.

V. Thiết Kế Cơ Sở Dữ Liệu Địa Lý

schema.sql PostgreSQL + PostGIS 
-- Kích hoạt tiện ích mở rộng PostGIS cho các tính năng địa lý
CREATE EXTENSION IF NOT EXISTS postgis;

-- 1. Bảng Người dùng
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    username VARCHAR(50) UNIQUE NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    avatar_url TEXT,
    exp_points INT DEFAULT 0,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 2. Bảng Quán Ẩn / Góc Sống Ảo (Gems)
CREATE TABLE gems (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name VARCHAR(150) NOT NULL,
    description TEXT,
    difficulty_level VARCHAR(20) DEFAULT 'medium', -- easy, medium, hard, extreme
    
    -- Trường tọa độ không gian sử dụng PostGIS (Sử dụng SRID 4326 đại diện cho GPS chuẩn thế giới)
    coordinates GEOMETRY(Point, 4326) NOT NULL,
    
    address TEXT,
    created_by UUID REFERENCES users(id) ON DELETE SET NULL,
    is_approved BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- Tạo không gian chỉ mục (Spatial Index) để tối ưu hóa việc truy vấn vị trí
CREATE INDEX idx_gems_coordinates ON gems USING GIST(coordinates);

-- 3. Bảng Video Review (Định dạng dọc kiểu TikTok)
CREATE TABLE gem_videos (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    gem_id UUID REFERENCES gems(id) ON DELETE CASCADE,
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    video_url TEXT NOT NULL,           -- Đường dẫn file phát trực tiếp (.m3u8)
    thumbnail_url TEXT,
    likes_count INT DEFAULT 0,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

VI. Thuật Toán & Tối Ưu Hóa Quan Trọng

1. Truy vấn địa điểm trong bán kính $R$ bằng PostGIS

Để tìm kiếm tất cả các "Gems" ẩn nằm trong phạm vi bán kính $R$ (mét) xung quanh vị trí GPS của người dùng, máy chủ Go sẽ tận dụng hàm ST_DWithin của PostGIS. Phương pháp này tận dụng trực tiếp chỉ mục không gian GIST để tìm kiếm nhanh chóng và bỏ qua các điểm vượt quá bán kính tính toán.

query_geo.go Go Code 
// $1: Kinh độ (Longitude), $2: Vĩ độ (Latitude), $3: Bán kính tìm kiếm (Radius tính bằng mét)
query := `
    SELECT id, name, difficulty_level, ST_X(coordinates) as longitude, ST_Y(coordinates) as latitude,
           ST_Distance(coordinates, ST_SetSRID(ST_MakePoint($1, $2), 4326)::geography) as distance_meters
    FROM gems
    WHERE ST_DWithin(coordinates::geography, ST_SetSRID(ST_MakePoint($1, $2), 4326)::geography, $3)
      AND is_approved = TRUE
    ORDER BY distance_meters ASC
    LIMIT 20;
`

2. Nguyên lý tối ưu hóa phát Video luồng của Flutter

Bí mật nằm sau khả năng cuộn video mượt mà không bị treo/lag ứng dụng do tràn bộ nhớ đồ họa là việc quản lý nghiêm ngặt vòng đời của các tài nguyên phát luồng.

Chỉ Dựng Trước 1 Video

Sử dụng cơ chế PreloadPageView để chỉ dựng sẵn tối đa 1 trang kề cận, tránh tải hàng loạt gây tốn băng thông và treo luồng chính.

Giải Phóng Ngay Lập Tức

Khi phần tử video vượt ra ngoài ranh giới vùng hiển thị (Viewport), kích hoạt hàm giải phóng bộ nhớ đồ họa bằng lệnh hủy controller ngay lập tức.

Phát luồng HLS & Cache

Sử dụng định dạng tệp phát luồng .m3u8, chia nhỏ các gói .ts và tải đệm cache cục bộ cho thiết bị để lần xem lại không cần mạng.
