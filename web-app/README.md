# TripWise Web Client App

The customer-facing web client for the TripWise smart travel planner. Bootstrapped with Next.js, React, TailwindCSS, and TypeScript.

## Features

- **AI Trip Planner**: Select destinations, preferences, budgets, and receive complete custom itineraries.
- **Interactive Map**: View selected locations and routes directly on the maps.
- **Community Feed**: Connect with other travellers, explore public collections, and share itineraries.
- **User Dashboard**: Manage profile details, collections, and past/future trips.

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Configure environment variables

Create a `.env.local` file at the root of `web-app` directory:

```env
NEXT_PUBLIC_API_URL=http://localhost:8080/api
```

### 3. Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
